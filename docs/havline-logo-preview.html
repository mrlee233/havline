Havline

让每条服务，安全抵达。

Havline 由 Haven（安全港湾）与 Line（连续链路）组成。标志把字母 H、港湾立柱与一条穿行线路叠成同一个符号，在 16px 下也能保留识别性。

HAV-LINE SAFE HARBOR + ROUTE
VECTOR IDENTITY / 2026

设计理念

品牌不强调“翻墙”或“穿透”的对抗感，而强调安全、可靠和持续连接。标志中的所有元素都指向同一个动作：服务从内网出发，沿着一条清晰的线路，安全抵达外部入口。

01 / HAVEN

安全港湾

左右两根立柱构成港湾的堤岸，也构成字母 H。它代表服务始终有一个稳定、可信的原点。

02 / LINE

连续链路

蓝色到青色的曲线横穿 H，把内网服务与公网入口连成一条连续的线路，暗示隧道、反代和远程访问。

03 / NODE

服务节点

线路两端的圆点分别代表服务和 Agent。节点让标志不仅仅是字母，更是一个可扩展的系统图。

04 / SCALE

小尺寸可读

主轮廓只有两根竖线、一条曲线和两个节点，避免复杂图形在 favicon、状态栏和移动端缩小时糊成一团。

标志构成

这个图形同时读取为 H、港湾和线路。第一眼是品牌字母，第二眼看到的是服务从 A 点到 B 点的路径。

A

H 的双柱

两根竖向立柱保持等宽和等距，形成稳定的字母骨架。圆角端点让技术图形不显得生硬。

B

一条服务线

曲线从左侧立柱出发，在中部抬升，再从右侧立柱穿出。它不是装饰线，而是整个标志的叙事核心。

C

两端的节点

起点和终点使用不同深浅的蓝色与青色，分别对应内网服务和公网入口，也方便后续扩展状态点。

D

圆角容器

深海底板提供高对比背景，适合应用图标、登录页、侧栏品牌区和公开状态页。

版本与背景

主版本适合深色 UI；浅色版本用于文档、邮件和打印；单色版本用于水印、丝印和不支持渐变的场景。

尺寸实验室

标志的核心结构在 16px 仍然保持 H 与线路的轮廓。拖动滑杆可以实时检查缩放后的清晰度。

96 px

建议最小使用尺寸：UI 图标 16px，应用图标 24px，侧栏品牌区 32px，登录页主标志 96px 以上。

色彩系统

深海蓝负责安全与稳定，潮汐蓝和青色负责线路与连接，港湾白负责结构。琥珀色只作为状态或警告的补充，不进入主标志。
